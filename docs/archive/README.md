# Documentation Archive

This directory contains completed or superseded project records. Archived
documents remain available for traceability, but they are not current
implementation authority.

Use the active [documentation index](../README.md) for architecture, contracts,
operations, research inputs, and current agent work.

## Contents

- [Coordination history](coordination/README.md) — completed Codex, Sonnet, and
  Kimi work packages, organized by UTC month.
- [Superseded documents](superseded/README.md) — retained legacy material that
  no longer describes the current system.

## Archive policy

- Move a task record here only after an independent reviewer marks it `DONE`.
- Keep unresolved decisions, active claims, corrections, and future work in the
  active documentation.
- Preserve task IDs, owners, scopes, decisions, verification results, and commit
  SHAs.
- Update every inbound link in the same commit.
- Treat Git history as the lossless source for earlier document layouts.
