## S2-02 — Read-only Core Network Probe Preflight

- **Owner:** SONNET5
- **Status:** PREFLIGHT COMPLETE; implementation gate remains S2-01 DONE
- **Preflight commit:** `b6c2e81`
- **Contract/API decision commit:** `67f13e0`
- **Inventory result:** none of ICMP, TCP, HTTP, DNS, or latency was registered
  by the collector entry point. Each computed `CheckResult.metrics`, but the
  scheduler consumed only run status/error, so no probe measurement reached
  OTel. Existing result labels exposed raw target/IP/URL/port/status/type data
  outside the bounded Metrics Contract.
- **Runtime findings:** ICMP used the default thread pool instead of the
  collector's capped executor; TCP/aiohttp were cancellation-safe; DNS had a
  lifetime bound requiring focused cancellation coverage; latency's sequential
  burst could exceed the scheduler timeout and shared ICMP targets would
  multiply packet volume silently.
- **Approved target/config design:** structured per-family targets with unique
  operator-assigned DNS-label-style `target_id`, at most 32 targets per family,
  independently validated operational host/port/URL values, enumerated DNS
  record types, and no raw target content in metrics. Add a separate
  `LatencyConfig`, disabled by default, rather than deriving bursts from ICMP
  targets. Per-family `enabled` gates construction; scan level remains an
  independent scheduler gate.
- **Approved metric design:** canonical seconds/ratio families for ICMP, TCP,
  HTTP, DNS, and distinct latency aggregate gauges; bounded `target_id`,
  HTTP `state`, and DNS `record_type` labels; logical budgets of 32 target
  series, 64 HTTP target/state series, and 256 DNS target/type series.
  `docs/contracts/METRICS.md` is authoritative.
- **Proposed exact implementation scope:** the five `collector/checks/net_*.py`
  modules; `collector/checks/__init__.py`; network/latency target sections of
  `collector/config.py`; check wiring in `collector/__main__.py`; the matching
  five probe test modules; `test_base.py`; target-validation portions of
  `test_config.py`; registration portions of `test_main.py`; active ledger.
- **Required test matrix:** canonical name/unit/label emission, target-ID
  isolation, success/failure/timeout, malformed target, ICMP permission denial,
  cancellation/no leaks, enabled/empty/scan-level registration, one instance
  per target, and real collector-to-storage/query integration.
