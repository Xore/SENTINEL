BROAD VIEW

LAN host discovery

Light ICMP/ARP host sweep of a directly-connected subnet plus the neighbour cache — IP, MAC, vendor and reverse-DNS name. Host discovery only, no port scan, never a payload to OT devices.

PASSIVE DIAGNOSTICS

Short Layer-2 health sample

Reports traffic rate, broadcasts, multicast, ARP, STP, discovery, OT protocols, retransmissions, resets and NIC drops.

SUPPORT BUNDLE

System/network snapshot

Records interfaces, routes, neighbors, DNS, time, driver counters, sockets and Wi-Fi state. The local result is hashed.

RF NEIGHBOURHOOD

AP / channel survey

Which APs are on air, on what channels/bands, and how the RF neighbourhood looks. Reads NetworkManager's scan cache (no root). Needs the radio enabled — if it is rfkill-blocked, enable the wireless switch/BIOS radio first.

RADIO HEALTH

Local Wi-Fi links

Signal, bitrate, channel and association data from local adapters. Deeper 802.11 management-frame analysis: run sudo scripts/wifi-monitor-capture.sh <iface> <channels> on the probe.
